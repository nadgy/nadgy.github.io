Tutoriel GIS : Calcul des Statistiques Zonales

Objectif

Ce tutoriel explique comment calculer les statistiques zonales dans QGIS. Les statistiques zonales permettent d'obtenir des données agrégées (comme la moyenne, la somme, ou le maximum) d'un raster en fonction des zones définies dans un shapefile.

1. Pré-requis

  • Logiciels installés : QGIS.
  • Fichiers nécessaires :
    • Un raster contenant les données à analyser (par exemple, un GeoTIFF).
    • Un shapefile définissant les zones d’analyse.

2. Charger les données dans QGIS

  1. Ouvrez QGIS.
  2. Ajoutez votre raster : Cliquez sur « Ajouter une couche raster », puis sélectionnez votre fichier raster (GeoTIFF).
  3. Ajoutez votre shapefile : Cliquez sur « Ajouter une couche vecteur », puis sélectionnez votre fichier shapefile (.shp).

3. Calcul des statistiques zonales

  1. Dans la barre de menus, cliquez sur « Traitement > Boîte à outils ».
  2. Dans la boîte à outils de traitement, recherchez « Statistiques zonales ».
  3. Double-cliquez sur l'outil « Statistiques zonales » pour l’ouvrir.
  4. Configurez les paramètres :
    • Raster d’entrée : Sélectionnez votre couche raster.
    • Zones vecteur : Sélectionnez votre shapefile.
    • Champ pour les résultats : Choisissez un champ dans lequel les résultats seront enregistrés (ou laissez QGIS en créer un automatiquement).
    • Statistiques à calculer : Cochez les statistiques que vous souhaitez (par exemple, Moyenne, Somme, Minimum, Maximum).
  5. Choisissez un emplacement pour enregistrer la sortie si nécessaire, puis cliquez sur « Exécuter ».

4. Vérifier les résultats

  1. Ouvrez la table attributaire de votre shapefile (clic droit sur la couche, puis « Ouvrir la table attributaire »).
  2. Vous verrez les nouvelles colonnes ajoutées contenant les statistiques calculées pour chaque zone.

5. Exporter les résultats

  1. Pour sauvegarder le shapefile avec les statistiques :
    • Faites un clic droit sur la couche, puis cliquez sur « Exporter > Enregistrer les entités sous ».
    • Choisissez un format (par exemple, ESRI Shapefile), un emplacement, et enregistrez.

Conclusion

Vous avez appris à calculer les statistiques zonales dans QGIS. Ces statistiques sont utiles pour analyser des données raster en fonction de zones géographiques spécifiques, comme des régions, des parcelles ou des bassins versants.

Matériel à fournir aux étudiants

  • Le fichier raster.
  • Le shapefile.
