Tutoriel GIS : Traitement d'un fichier GeoTIFF avec shapefile

Objectif

Apprendre à télécharger, traiter et utiliser un fichier GeoTIFF à partir de USGS, puis le découper à l’aide d’un shapefile. Vous utiliserez des outils SIG comme QGIS.

1. Pré-requis

  • Logiciels installés : QGIS (gratuit et open-source).
  • Fichiers nécessaires :
    • Un fichier GeoTIFF téléchargé depuis USGS.
    • Votre shapefile (SHP) contenant la zone d’intérêt.

2. Téléchargement d’un fichier GeoTIFF depuis USGS

  1. Rendez-vous sur le site de USGS.
  2. Connectez-vous avec vos identifiants.
  3. Accédez à la section « Téléchargement de données » et sélectionnez les données raster (GeoTIFF).
  4. Téléchargez le fichier GeoTIFF et enregistrez-le sur votre ordinateur.

3. Charger le fichier GeoTIFF dans QGIS

  1. Ouvrez QGIS.
  2. Dans la barre d’outils, cliquez sur « Ajouter une couche raster ».
  3. Sélectionnez le fichier GeoTIFF que vous avez téléchargé.
  4. Visualisez le raster sur votre carte. Vous devriez voir votre image GeoTIFF chargée dans la fenêtre principale.

4. Charger le shapefile dans QGIS

  1. Cliquez sur « Ajouter une couche vecteur ».
  2. Sélectionnez votre shapefile (fichier .shp).
  3. Une fois chargé, le shapefile apparaîtra comme une couche superposée sur le raster.

5. Découper le GeoTIFF avec le shapefile

  1. Dans la barre de menus, allez dans « Traitement > Boîte à outils ».
  2. Cherchez « Extraction par masque » dans la boîte à outils (ou tapez « clip raster by mask layer » dans la recherche).
  3. Configurez les paramètres :
    • Raster à découper : Sélectionnez votre couche GeoTIFF.
    • Masque de découpe : Choisissez votre shapefile.
    • Assurez-vous que l’option « Aligner avec le masque » est activée.
  4. Choisissez un emplacement pour enregistrer le fichier découpé, puis cliquez sur « Exécuter ».

6. Vérifier et sauvegarder le fichier découpé

  1. Une nouvelle couche raster découpée apparaîtra dans QGIS.
  2. Vous pouvez sauvegarder le résultat :
    • Faites un clic droit sur la couche découpée.
    • Sélectionnez « Exporter > Enregistrer sous ».
    • Choisissez le format (par exemple, GeoTIFF), donnez un nom au fichier et cliquez sur « OK ».

7. Analyse des données découpées

Si nécessaire, vous pouvez analyser le raster découpé en utilisant les outils QGIS :

  • Statistiques zonales pour analyser les valeurs dans la zone du shapefile.
  • Calculatrice raster pour manipuler les valeurs des pixels.

Conclusion

Vous avez appris à télécharger un fichier GeoTIFF depuis USGS, le charger dans QGIS, et le découper selon un shapefile. Ce processus est utile pour limiter une analyse à une zone spécifique et éviter de traiter des données inutiles.

Matériel à fournir aux étudiants

  • Le fichier GeoTIFF.
  • Le shapefile.
  • Une version PDF de ce tutoriel.
